# QA module — Phase 7: Guest UAT — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a client take part in UAT as a guest: invited to specific projects, seeing only their QA, signing plans off, while the team can hand anyone a read-only, revocable report link.

**Architecture:** Guests were modelled in Phase 1 (role `guest`, `project_members`, `authz.RequireProjectAccess`); this phase gives them a way in (invitations that name projects, a Guests panel), a shell that shows nothing but their QA (a 404 rule in `authz.Require`, a sidebar trimmed in `renderPage`), and the two UAT outcomes: sign-offs (`qa_signoffs`) and the plan report with share links (`qa_share_links`), both tables created in Phase 1. Every new QA route goes through `qaRoute`; the one public route (`/s/qa/:token`) is `authz.Public` and checks its own token against the host's organization.

**Tech Stack:** Go 1.26, Fiber v2, html/template, htmx, Alpine.js, Basecoat combobox (`lotus_select`), Postgres 16+, goose, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-27-qa-module-design.md` (§3 client UAT, §4 `project_members`, `qa_signoffs`, `qa_share_links`; §5 permissions and "own projects"). **Parent plan:** `docs/superpowers/plans/2026-09-27-qa-module.md`, "Phase 7 — Guest UAT". **Previous phases:** `…/2026-09-27-qa-phase-4.md` to `…-phase-6.md` (helpers used here: `qaRoute`, `qaOwned`, `qaNav`, `qaFormError`, `qaProjectScope`, `qaPeopleLabels`, `personLabel`, `qaPhaseLabels`, `qaWindow`, `qaSeverityTone`, `repo.QAPlanProgress`, `repo.QARunProgressFor`, `repo.QAOpenIssueStatuses`; test helpers `newQAEnv`, `newQARunEnv`, `mustPlanScenarios`, `auditCount`, `decisionFor`).

## Decisions

- **The settings invite now sends the invitation.** Until now the members screen only wrote an invitation row: no email, no link shown. Task 1 routes it through `authn.SendInvitation`, the path the API already used. It emails the link when mail is set up and shows the link in the dialog either way (production has no SMTP), and it applies the existing rate limits: 3 invitations per address per day and 20 per organization per hour.
- **A guest's pages outside QA are 404, not 403**, including Settings. The outline said "settings except own tokens". The guest role has had no `token.manage.own` since Phase 1, so a guest has no token screen, and nothing in Phase 8 needs one. *To revisit:* if clients should call the API, add `token.manage.own` to the guest role and let `/settings/tokens` through.
- **Changing a guest to a member keeps its project list.** It is not consulted while the role is not guest, and it applies again if the role goes back to guest.
- **A sign-off note is required unless the decision is a plain accept.** "Accepted with notes" and "Rejected" must say what. Sign-offs are append-only; the page shows the latest per scope, the audit log keeps them all.
- **The shared report names signers but never shows their email addresses.** A signer with no name shows as "—". The report has no attachments, no forms and no links into the app. Open issues show key, title, severity and status.
- **One report serves both audiences.** Signed in, it is at `…/plans/:pid/report` for anyone with `qa.read` (guests included). Shared, it is at `/s/qa/:token`. It is a standalone page that prints as it reads.

## Rulings (where this plan departs from the Phase 7 outline)

1. **"Removing a project hides it immediately"** holds because `RequireProjectAccess` reads `project_members` on every request; Task 1's test removes the guest from a project and gets 404 on its next request, with no session change.
2. **The guest crawl allows 403 inside its own project's QA.** The outline says only QA routes of its projects answer 200. Write pages a guest may not use, such as a new case or the CSV import, answer 403 there. That matches the rule elsewhere: a known page, not your action. Everything outside QA is 404.
3. **Guest sessions are not rotated when their project list changes.** Membership is checked per request, so a stale cookie cannot reach a removed project.

## Global Constraints

- Everything in Phases 4–6's Global Constraints still holds.
- Permissions exactly as spec §5:
  - `project_member.manage`: the Guests panel. Owner and admin.
  - `qa.signoff`: sign-off. Owner, admin, and a guest on its projects; members do not have it.
  - `qa.share`: share links. Owner, admin and member.
  - `qa.read`: the report.
- Share tokens: 32 random bytes, hex; only the sha256 is stored; 30-day expiry; revocable; never logged or flashed.
- Migrations must run on Postgres 16 (production) and 17 (development).

## Review Focus

1. **A guest reaching anything outside its projects' QA**: another project's QA, dashboard, metrics, integrations, activity, settings, the project page. It must get 404. Pinned by Task 2's crawl and Task 1's project-list test.
2. **A share token used anywhere but `/s/qa/:token`**: as a session cookie, on another organization's host, after revoke or expiry. It must never open anything. Pinned in Task 4.
3. **What the shared report leaks**: forms, attachment URLs, links into the app, email addresses, markup in issue titles. None of them may appear. Pinned in Task 4.
4. **Guest listings by the wrong hands or of the wrong people**: an invitation naming another organization's project is refused with a message; a member adding a guest gets 403; adding someone who is not a guest of this organization is 404. Pinned in Task 1.
5. **Sign-off input**: a scenario outside the plan, an unknown decision, or a rejection without a note is refused with a message and nothing is written; the page shows only the latest per scope. Pinned in Task 3.

### Task 1: Guests: invite to projects, the project's Guests panel, role changes

The members screen offers **Guest**. Choosing it needs at least one project of this organization (checkboxes under PROJECTS · GUESTS ONLY), and the invitation stores them (`invitations.project_ids`, migration 00029). Accepting a guest invitation lists the guest on those projects in `project_members`, in the same transaction; a resend keeps the projects. The invite now goes through `authn.SendInvitation`, like the API: it emails the link when mail is set up, applies the invitation rate limits and the owner guard, and the dialog shows the link either way. On the project page, `project_member.manage` gets a **Guests** card: the guests listed on the project (each removable) and a select of the organization's other guests to add. Adding checks the person is an active guest of this organization (404 otherwise), and both actions are audited (`project_member.add`, `project_member.remove`). An admin can change a guest to a member and back; the project list stays and applies again when the role is guest.

func projectGuestsFor(c *fiber.Ctx, d Deps, s tenant.Scope, projectID uuid.UUID) (projectGuestsView, error) {
	var v projectGuestsView

	listed, err := repo.ListProjectMemberUserIDs(c.Context(), s, projectID)

	}

	for _, id := range listed {
		on[id] = true
	}
	v.Options = []httpx.SelectOption{}
	for _, m := range members {
		if m.RoleKey != "guest" {
			continue
		}

			label = m.Email
		} else {
			label += " · " + m.Email
		}
		if on[m.UserID] {
			v.Listed = append(v.Listed, projectGuest{ID: m.UserID, Label: label})

		}
	}

// guestHome sends a guest from the landing page (/projects, where / and
// every login lead) to its own work.
func guestHome(c *fiber.Ctx) error {
	if p, ok := authz.CurrentPrincipal(c); ok && authz.IsProjectScoped(p) {
		return c.Redirect("/qa/my", fiber.StatusFound)
	}
	return c.Next()
}

// guestNav replaces the sidebar for a guest. Pages build the one everybody
// else sees; renderPage trims it here so no page has to remember to.
func guestNav(c *fiber.Ctx, nav *httpx.Nav) {
	p, ok := authz.CurrentPrincipal(c)
	if !ok || !authz.IsProjectScoped(p) {
		return
	}
	nav.Guest = true
	nav.FooterItems = nil
	nav.Items = []httpx.NavItem{{Key: "qa_tools", Label: "My work", Href: "/qa/my", Icon: iconQATools}}
	nav.Active = "qa_tools"
	s, ok := tenant.FromContext(c)
	if !ok {
		return
	}
	ids, err := repo.ListProjectIDsForMember(c.Context(), s, p.UserID)
	if err != nil || len(ids) == 0 {
		return
	}
	listed := make(map[string]bool, len(ids))
	for _, id := range ids {
		listed[id.String()] = true
	}
	projects, err := repo.ListProjects(c.Context(), s, false)
	if err != nil {
		return
	}
	for _, project := range projects {
		if !listed[project.ID.String()] {
			continue
		}
		key := "qa_project_" + project.ID.String()
		href := "/projects/" + project.ID.String() + "/qa"
		nav.Items = append(nav.Items, httpx.NavItem{Key: key, Label: project.Name, Href: href, Icon: iconProjects})
		if c.Path() == href || strings.HasPrefix(c.Path(), href+"/") {
			nav.Active = key
		}
	}
}

package repo

import (
	"context"
	"strings"
	"time"
	"unicode/utf8"

	"github.com/google/uuid"
	"github.com/jmoiron/sqlx"

	"github.com/uyab/lotus/internal/tenant"

// A sign-off is a client's (or an admin's) verdict on a plan, for the whole
// plan or for one of its scenarios. Sign-offs are never edited: a new one
// supersedes the last for the same scope, and the history stays.

// QASignoffDecisions in the order the form offers them.
var QASignoffDecisions = []string{"accepted", "accepted_with_notes", "rejected"}

// MaxQASignoffNote bounds a sign-off note, in runes.
const MaxQASignoffNote = 4000

type QASignoff struct {
	ID         uuid.UUID  `db:"id"`
	PlanID     uuid.UUID  `db:"plan_id"`
	ScenarioID *uuid.UUID `db:"scenario_id"` // nil: the whole plan
	Decision   string     `db:"decision"`
	Note       string     `db:"note"`
	SignedBy   *uuid.UUID `db:"signed_by"`
	SignedAt   time.Time  `db:"signed_at"`
}

const qaSignoffCols = `id, plan_id, scenario_id, decision, note, signed_by, signed_at`

type QASignoffInput struct {
	ScenarioID *uuid.UUID
	Decision   string
	Note       string
}

func (in QASignoffInput) normalized() (QASignoffInput, error) {
	in.Note = strings.TrimSpace(in.Note)
	valid := false
	for _, d := range QASignoffDecisions {
		valid = valid || d == in.Decision
	}
	switch {
	case !valid, utf8.RuneCountInString(in.Note) > MaxQASignoffNote:
		return in, ErrInvalidInput
	case in.Decision != "accepted" && in.Note == "":
		// Anything short of a plain accept has to say what is wrong.
		return in, ErrInvalidInput
	}
	return in, nil
}

// RecordQASignoff signs off planID, or one of its scenarios.
func RecordQASignoff(ctx context.Context, s tenant.Scope, planID uuid.UUID, in QASignoffInput, by *uuid.UUID) (*QASignoff, error) {
	in, err := in.normalized()
	if err != nil {
		return nil, err
	}
	var out QASignoff
	err = s.Tx(ctx, func(tx *sqlx.Tx) error {
		if in.ScenarioID != nil {
			var n int
			if err := tx.GetContext(ctx, &n, `
				SELECT count(*) FROM qa_plan_scenarios WHERE plan_id = $1 AND scenario_id = $2`, planID, *in.ScenarioID); err != nil {
				return err
			}
			if n == 0 {
				return ErrInvalidInput
			}
		}
		return tx.GetContext(ctx, &out, `
			INSERT INTO qa_signoffs (org_id, plan_id, scenario_id, decision, note, signed_by)
			VALUES ($1, $2, $3, $4, $5, $6) RETURNING `+qaSignoffCols,
			s.OrgID(), planID, in.ScenarioID, in.Decision, in.Note, by)
	})
	if err != nil {
		return nil, qaWriteErr(err)
	}
	return &out, nil
}

// ListLatestQASignoffs is the standing sign-off per scope of planID: the
// whole plan first, then each signed scenario.
func ListLatestQASignoffs(ctx context.Context, s tenant.Scope, planID uuid.UUID) ([]QASignoff, error) {
	var out []QASignoff
	err := s.Tx(ctx, func(tx *sqlx.Tx) error {
		return tx.SelectContext(ctx, &out, `
			SELECT DISTINCT ON (scenario_id) `+qaSignoffCols+` FROM qa_signoffs
			WHERE plan_id = $1
			ORDER BY scenario_id NULLS FIRST, signed_at DESC, id DESC`, planID)
	})
	return out, err
}

		byScope[key] = so
	}
	row := func(scope string, key uuid.UUID) qaSignoffRow {

			r.Decision, r.Label, r.Tone, r.Note = so.Decision, qaSignoffLabels[so.Decision], qaSignoffTones[so.Decision], so.Note

import (
	"context"
	"time"

	"github.com/google/uuid"
	"github.com/jmoiron/sqlx"

// A share link opens one plan's read-only report to whoever holds it, with
// no login (/s/qa/:token). Only the token's sha256 is stored; a link lasts
// QAShareLinkTTL unless revoked first.

const QAShareLinkTTL = 30 * 24 * time.Hour

type QAShareLink struct {
	ID        uuid.UUID  `db:"id"`
	PlanID    uuid.UUID  `db:"plan_id"`
	ExpiresAt time.Time  `db:"expires_at"`
	RevokedAt *time.Time `db:"revoked_at"`
	CreatedBy *uuid.UUID `db:"created_by"`
	CreatedAt time.Time  `db:"created_at"`
}

const qaShareLinkCols = `id, plan_id, expires_at, revoked_at, created_by, created_at`

func CreateQAShareLink(ctx context.Context, s tenant.Scope, planID uuid.UUID, tokenHash string, by *uuid.UUID) (*QAShareLink, error) {
	var out QAShareLink
	err := s.Tx(ctx, func(tx *sqlx.Tx) error {
		return tx.GetContext(ctx, &out, `
			INSERT INTO qa_share_links (org_id, plan_id, token_hash, expires_at, created_by)
			VALUES ($1, $2, $3, now() + $4 * interval '1 second', $5) RETURNING `+qaShareLinkCols,
			s.OrgID(), planID, tokenHash, int64(QAShareLinkTTL/time.Second), by)
	})
	if err != nil {
		return nil, qaWriteErr(err)
	}
	return &out, nil
}

// QAShareLinkByHash is the live link with this token hash: ErrNotFound when
// there is none, or it was revoked, or it has expired.
func QAShareLinkByHash(ctx context.Context, s tenant.Scope, tokenHash string) (*QAShareLink, error) {
	var out QAShareLink
	err := s.Tx(ctx, func(tx *sqlx.Tx) error {
		return tx.GetContext(ctx, &out, `
			SELECT `+qaShareLinkCols+` FROM qa_share_links
			WHERE token_hash = $1 AND revoked_at IS NULL AND expires_at > now()`, tokenHash)
	})
	if err != nil {
		return nil, qaWriteErr(err)
	}
	return &out, nil
}

// ListQAShareLinks is planID's live links, newest first.
func ListQAShareLinks(ctx context.Context, s tenant.Scope, planID uuid.UUID) ([]QAShareLink, error) {
	var out []QAShareLink
	err := s.Tx(ctx, func(tx *sqlx.Tx) error {
		return tx.SelectContext(ctx, &out, `
			SELECT `+qaShareLinkCols+` FROM qa_share_links
			WHERE plan_id = $1 AND revoked_at IS NULL AND expires_at > now()
			ORDER BY created_at DESC, id`, planID)
	})
	return out, err
}

// RevokeQAShareLink ends a live link of planID at once.
func RevokeQAShareLink(ctx context.Context, s tenant.Scope, planID, id uuid.UUID) error {
	return s.Tx(ctx, func(tx *sqlx.Tx) error {
		res, err := tx.ExecContext(ctx, `
			UPDATE qa_share_links SET revoked_at = now()
			WHERE id = $1 AND plan_id = $2 AND revoked_at IS NULL`, id, planID)
		if err != nil {
			return err
		}
		return checkRowsAffected(res)
	})
}

// QAPlanScenarioProgress is, for each scenario of planID, the latest status
// (highest cycle) of each of its cases that the plan's runs hold.
func QAPlanScenarioProgress(ctx context.Context, s tenant.Scope, planID uuid.UUID) (map[uuid.UUID]QAProgress, error) {
	var rows []struct {
		ScenarioID uuid.UUID `db:"scenario_id"`
		Status     string    `db:"status"`
		N          int       `db:"n"`
	}
	err := s.Tx(ctx, func(tx *sqlx.Tx) error {
		return tx.SelectContext(ctx, &rows, `
			SELECT si.scenario_id, latest.status, count(*) AS n
			FROM (
				SELECT DISTINCT ON (i.case_id) i.case_id, i.status
				FROM qa_run_items i JOIN qa_runs r ON r.id = i.run_id
				WHERE r.plan_id = $1
				ORDER BY i.case_id, r.cycle DESC
			) latest
			JOIN qa_scenario_items si ON si.case_id = latest.case_id
			JOIN qa_plan_scenarios ps ON ps.scenario_id = si.scenario_id AND ps.plan_id = $1
			GROUP BY si.scenario_id, latest.status`, planID)
	})
	out := map[uuid.UUID]QAProgress{}
	for _, r := range rows {
		p := out[r.ScenarioID]
		p.add(r.Status, r.N)
		out[r.ScenarioID] = p
	}
	return out, err
}

// buildQAReport gathers the report; shared is true for a share link, whose
// holder is nobody in particular (see qaPlanSignoffs).
func buildQAReport(c *fiber.Ctx, d Deps, s tenant.Scope, project *repo.Project, plan *repo.QAPlan, shared bool) (qaReportData, error) {
	data := qaReportData{ProjectName: project.Name, Plan: *plan, Shared: shared, PhaseLabel: qaPhaseLabels[plan.Phase],
		Window: qaWindow(plan.StartsOn, plan.EndsOn), Generated: time.Now().Format("02 Jan 2006 15:04")}
	progress, err := repo.QAPlanProgress(c.Context(), s, []uuid.UUID{plan.ID})
	if err != nil {
		return data, err
	}
	data.Progress = progress[plan.ID]

	ids, err := repo.ListQAPlanScenarioIDs(c.Context(), s, plan.ID)
	if err != nil {
		return data, err
	}
	inPlan := map[uuid.UUID]bool{}
	for _, id := range ids {
		inPlan[id] = true
	}
	all, err := repo.ListQAScenarios(c.Context(), s, project.ID, true)
	if err != nil {
		return data, err
	}
	perScenario, err := repo.QAPlanScenarioProgress(c.Context(), s, plan.ID)
	if err != nil {
		return data, err
	}
	var rows []qaScenarioRow
	for _, sc := range all {
		if inPlan[sc.ID] {
			rows = append(rows, qaScenarioRow{QAScenario: sc})
			data.Scenarios = append(data.Scenarios, qaReportScenario{Name: sc.Name, PhaseLabel: qaPhaseLabels[sc.Phase], Progress: perScenario[sc.ID]})
		}
	}
	if data.Signoffs, err = qaPlanSignoffs(c, d, s, plan.ID, rows, shared); err != nil {
		return data, err
	}

	runs, err := repo.ListQARuns(c.Context(), s, plan.ID)
	if err != nil {
		return data, err
	}
	runIDs := make([]uuid.UUID, len(runs))
	for i, r := range runs {
		runIDs[i] = r.ID
	}
	runProgress, err := repo.QARunProgressFor(c.Context(), s, runIDs)
	if err != nil {
		return data, err
	}
	for _, r := range runs {
		data.Runs = append(data.Runs, qaReportRun{Name: r.Name, Cycle: r.Cycle, Closed: r.ClosedAt != nil, Progress: runProgress[r.ID]})
	}

	issues, err := repo.ListQAIssues(c.Context(), s, project.ID, repo.QAIssueFilter{Statuses: repo.QAOpenIssueStatuses, PlanID: &plan.ID})

}

var qaShareTokenPattern = regexp.MustCompile(`^[0-9a-f]{64}$`)

func qaShareTokenHash(raw string) string {
	sum := sha256.Sum256([]byte(raw))
	return hex.EncodeToString(sum[:])
}

// qaSharedReport is GET /s/qa/:token: no session, the token is the whole
// authorization, and it answers for one plan's report only. Anything wrong
// with it (unknown, revoked, expired, another organization's) is 404.
func qaSharedReport(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		// A link is a secret: not cached, not indexed, not leaked onward.
		c.Set("Cache-Control", "no-store")
		c.Set("X-Robots-Tag", "noindex, nofollow")
		c.Set("Referrer-Policy", "no-referrer")
		token := c.Params("token")
		if !qaShareTokenPattern.MatchString(token) {
			return fiber.ErrNotFound
		}
		s, err := mustScope(c)
		if err != nil {
			return err
		}
		link, err := repo.QAShareLinkByHash(c.Context(), s, qaShareTokenHash(token))
		if errors.Is(err, repo.ErrNotFound) {
			return fiber.ErrNotFound
		}
		if err != nil {
			return writeRepoErr(c, err)
		}
		plan, err := repo.GetQAPlan(c.Context(), s, link.PlanID)
		if err != nil {
			return writeRepoErr(c, err)
		}
		project, err := repo.ProjectByID(c.Context(), s, plan.ProjectID)
		if err != nil {
			return writeRepoErr(c, err)
		}
		data, err := buildQAReport(c, d, s, project, plan, true)
		if err != nil {
			return writeRepoErr(c, err)
		}
		data.ExpiresOn = link.ExpiresAt.Format("02 Jan 2006")
		return renderQAReport(c, d, data)
	}
}

// seedGuest adds a guest to orgId, lists it on projectId and returns a
// session cookie value for it.
export async function seedGuest(orgId: string, projectId: string, host: string): Promise<{ userId: string; sessionToken: string }> {
  return withDB(async (c) => {
    const u = await c.query(`INSERT INTO users (email, name, email_verified_at) VALUES ($1, 'Client Reviewer', now()) RETURNING id`,
      [`client-${randomUUID().slice(0, 8)}@bank.example`]);
    const userId = u.rows[0].id as string;
    await c.query(`INSERT INTO memberships (org_id, user_id, role_id) SELECT $1, $2, r.id FROM roles r WHERE r.key = 'guest' AND r.org_id IS NULL`, [orgId, userId]);
    await c.query(`INSERT INTO project_members (org_id, project_id, user_id) VALUES ($1, $2, $3)`, [orgId, projectId, userId]);
    const sessionToken = randomUUID();
    await c.query(`INSERT INTO sessions (id, user_id, org_id, host, expires_at) VALUES ($1, $2, $3, $4, now() + interval '1 day')`,
      [createHash('sha256').update(sessionToken).digest('hex'), userId, orgId, host]);
    return { userId, sessionToken };
  });
}
