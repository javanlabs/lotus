# QA module — Phase 5: Plans, runs, execution — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let QA plan cycles and run them in Lotus: plans over scenarios, runs with testers and a live distribution preview, an execution view where results, comments and files are recorded in place, bulk assignment, retests, closing, My work across projects, and saving a run as a scenario.

**Architecture:** The same shape as Phase 4. Server-rendered pages under `/projects/:id/qa/…`, each registered with `qaRoute` (tenant, session, principal, `RequireProjectAccess`, permission), and every id from the URL or a form checked against the project (`qaOwned`, or scoped by the repo). The execution view loads each item's details as an htmx fragment when opened, and answers a recorded result with that fragment plus out-of-band swaps of the row status and the progress header. Files go to the blob store (`Deps.Blob`) through `repo.SaveQAAttachment`.

**Tech Stack:** Go 1.26, Fiber v2, html/template, htmx, Alpine.js, Basecoat combobox (`lotus_select`), Postgres 16+, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-27-qa-module-design.md` (§3 hierarchy, §5 permissions). **Parent plan:** `docs/superpowers/plans/2026-09-27-qa-module.md`, "Phase 5 — Plans, runs, execution" (the outline this plan expands). **Previous phase:** `docs/superpowers/plans/2026-09-27-qa-phase-4.md` (helpers this plan uses: `qaRoute`, `qaOwned`, `qaNav`, `qaFormError`, `redirectAfterCreate`, test helpers `newQAEnv`, `seedQALibrary`).

**Status:** Validated. Every task was implemented in a scratch worktree exactly as written, one commit per task. Each commit on its own passes `go build`, `go vet`, `gofmt`, `make lint` and its tests. After Task 7 the full Go suite and all 34 Playwright specs pass. The code is also kept as `docs/superpowers/plans/2026-09-27-qa-phase-5.patch` (applies to `main` at `ab175a6`) for reference; the plan is the authority.

## Decisions

- **My work** lives at `/qa/my`, reached from a segmented control on the QA overview (Projects · My work). The sidebar's existing QA Tools entry shows the viewer's untested count. No new sidebar entry is added, keeping the sidebar decided in Phase 4.
- **The execution view expands items in place** rather than opening a page per item. A tester works down a group without losing their place, and the page reads no history until an item is opened.
- **Plan progress** is where each case stands now: its status in the latest cycle that holds it. The latest run alone would mislead, because a retest holds only the failed and blocked cases.
- **Testers** are the people who can execute: owners, admins, members, and guests listed on the project. Viewers cannot execute, so they are never offered.

## Rulings (where this plan departs from the Phase 5 outline)

1. **The request limit rises to 25 MB app-wide.** The outline's 20 MB attachments cannot arrive under Fiber's 4 MB default. *Cost if wrong:* larger requests on every route. All are authenticated or refused early by the tenant and session guards.
2. **Three repo defects from the Phase 1–3 review are fixed here** (Task 1): run in a closing plan, result in a closing run, result history order. The execution UI makes them reachable.
3. **The plan page has no sign-off placeholder.** Sign-off is Phase 7; an empty panel would only say "later".
4. **Phase 4's scenario-page note was wrong** ("archived cases will still be copied into new runs"). `CreateQARun` leaves them out. Task 1 corrects the copy and the repo comment.
5. **"Create scenario from run"** (moved from Phase 4) is Task 7.
6. **Large runs and scenarios are not paged** (Task 8, added from production sizes with the user). Paging would split a group's progress and its select-whole-group assignment, so past 200 items their groups start closed instead. *Cost if wrong:* a single 1,000-item group still renders in full when opened.

## Global Constraints

- Everything in Phase 4's Global Constraints still holds: `qaRoute` on every `/projects/:id/qa…` route, 404 for foreign ids, form POSTs with htmx rejections in place, `lotus_select`, the object form of Alpine `:style`, the design system's icons and copy rules, and raw SQL only in `internal/repo`.
- Permissions exactly as spec §5:
  - `qa.read`: plans, runs, items, files, My work.
  - `qa.plan.write`: plans, runs, assignment, retest, close.
  - `qa.execute`: recording results.
  - `qa.case.write`: saving a run as a scenario.
- Closing a plan or a run writes one `audit_events` row (`qa.plan.close`, `qa.run.close`); closing again writes none.
- Attachments: at most `repo.MaxQAAttachmentBytes` (20 MB) each, checked before the result is recorded. They are served only through their own project, with `X-Content-Type-Options: nosniff` and `Content-Security-Policy: sandbox`, and inline only for non-SVG images.

## Review Focus

1. **An id from another run or project**, whether an item via `:iid`, an attachment via `/files/:aid`, a scenario or tester in the new-run form, or an item or assignee in the assignment form, must be 404 or skipped. Pinned in Tasks 3, 4 and 5.
2. **Concurrent closing**: a run created, or a result recorded, while its plan or run is being closed must be refused, and two testers recording the same item must leave the history's latest entry matching the item. The first two are pinned deterministically in Task 1. The last is fixed (`clock_timestamp()`) but no test can force its interleaving.
3. **Uploaded files as content**: HTML, SVG or anything a browser might run must download, never render in the app's origin; a screenshot sent as `octet-stream` is sniffed so it still shows inline. Pinned in Task 4.
4. **Guests executing UAT**: a guest records results on its project's runs, and cannot assign, retest, close or create runs. Its My work covers only its projects, and removal from a project hides that project's items at once. Pinned in Tasks 3, 4, 5 and 6.
5. **Large runs**: the largest production run holds 1,089 items. Past 200 items, runs and scenarios open with their groups closed (Task 8). History loads per item, and bulk assignment of 200 items is one request. Still open the largest imported run by hand after the import.

## Tasks

### Task 1: Foundations: repo races, retest names, blob store, body limit, archived-case copy

Three repo defects deferred from the Phase 1–3 review become visible once people execute runs, so they are fixed first. A run created while its plan is being closed must not land in the closed plan, and a result recorded while its run is being closed must not land in the closed run. The plan and run rows are now read under lock; a result takes the run row `FOR SHARE`, so testers of one run still record in parallel. Results are stamped with `clock_timestamp()`, so history order matches the item's status when two testers record the same item. A retest is named `<run> — retest`: it stays within 200 characters and does not grow on a retest of a retest. The web server gets the blob store (`Deps.Blob`, from `LOTUS_BLOB_DIR`) and a 25 MB request limit, because attachments go up to 20 MB and Fiber's 4 MB default would refuse them before any handler runs. The scenario page's note about archived cases is corrected: `CreateQARun` leaves archived cases out; it does not copy them as Phase 4 said.

- Race tests hold the plan or run row in one transaction (`s.Tx`) while the call under test runs in a goroutine, then close the row and commit. They are deterministic: without the lock, the call does not wait.

// qaWindow is a plan's date window as people read it: "01 Sep – 14 Sep
// 2026", "from 01 Sep 2026", "" when there is none.
func qaWindow(start, end *time.Time) string {
	switch {
	case start != nil && end != nil && start.Year() == end.Year():
		return start.Format("02 Jan") + " – " + end.Format("02 Jan 2006")
	case start != nil && end != nil:
		return start.Format("02 Jan 2006") + " – " + end.Format("02 Jan 2006")
	case start != nil:
		return "from " + start.Format("02 Jan 2006")
	case end != nil:
		return "until " + end.Format("02 Jan 2006")
	}
	return ""
}

// readQAPlanForm reads a submitted plan. msg is the sentence to show for a
// rejected form; a scenario of another project is 404.
func readQAPlanForm(c *fiber.Ctx, s tenant.Scope, project *repo.Project) (repo.QAPlanInput, string, error) {
	in := repo.QAPlanInput{
		Name: c.FormValue("name"), Phase: strings.TrimSpace(c.FormValue("phase")),
		Environment: c.FormValue("environment"), Build: c.FormValue("build"),
	}
	if _, ok := qaPhaseLabels[in.Phase]; !ok {
		return in, "Choose a phase.", nil
	}
	for _, f := range []struct {
		field string
		to    **time.Time
	}{{"starts_on", &in.StartsOn}, {"ends_on", &in.EndsOn}} {
		raw := strings.TrimSpace(c.FormValue(f.field))
		if raw == "" {
			continue
		}
		d, err := time.Parse("2006-01-02", raw)
		if err != nil {
			return in, "Dates are written as YYYY-MM-DD.", nil
		}
		*f.to = &d
	}
	if in.StartsOn != nil && in.EndsOn != nil && in.EndsOn.Before(*in.StartsOn) {
		return in, "The end date is before the start date.", nil
	}
	for _, raw := range c.Context().PostArgs().PeekMulti("scenario_id") {
		id, err := qaOwned(c, s, project, repo.QAKindScenario, string(raw))
		if err != nil {
			return in, "", err
		}
		in.ScenarioIDs = append(in.ScenarioIDs, id)
	}
	return in, "", nil
}

func qaPlanNameErr(err error) (int, string, bool) {
	if errors.Is(err, repo.ErrInvalidInput) {
		return fiber.StatusUnprocessableEntity,
			fmt.Sprintf("Plan name is required and can be at most %d characters.", repo.MaxQANameLength), true
	}
	return 0, "", false
}

// loadQAPlan reads :pid, which must be a plan of the project in the URL.
func loadQAPlan(c *fiber.Ctx, s tenant.Scope, project *repo.Project) (*repo.QAPlan, error) {
	id, err := qaOwned(c, s, project, repo.QAKindPlan, c.Params("pid"))
	if err != nil {
		return nil, err
	}
	return repo.GetQAPlan(c.Context(), s, id)
}

func qaPlansPage(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		data := qaPlansData{Project: *project, Base: qaBase(project), Phase: c.Query("phase"),
			CanWrite: mustPrincipal(c).Can("qa.plan.write")}
		if _, ok := qaPhaseLabels[data.Phase]; !ok {
			data.Phase = ""
		}
		data.Filters = append([]httpx.SelectOption{{Value: "", Label: "All phases"}}, qaPhaseOptions()...)
		plans, err := repo.ListQAPlans(c.Context(), s, project.ID) // open first, newest first
		if err != nil {
			return writeRepoErr(c, err)
		}
		ids := make([]uuid.UUID, 0, len(plans))
		for _, p := range plans {
			if data.Phase == "" || p.Phase == data.Phase {
				ids = append(ids, p.ID)
			}
		}
		progress, err := repo.QAPlanProgress(c.Context(), s, ids)
		if err != nil {
			return writeRepoErr(c, err)
		}
		runs, err := repo.QAPlanRunCounts(c.Context(), s, ids)
		if err != nil {
			return writeRepoErr(c, err)
		}
		for _, p := range plans {
			if data.Phase != "" && p.Phase != data.Phase {
				continue
			}
			data.Rows = append(data.Rows, qaPlanRow{QAPlan: p, PhaseLabel: qaPhaseLabels[p.Phase], Window: qaWindow(p.StartsOn, p.EndsOn),
				Runs: runs[p.ID], Progress: progress[p.ID], Href: data.Base + "/plans/" + p.ID.String()})
		}
		if data.CanWrite {
			scenarios, err := qaPlanScenarioOptions(c, s, project, nil)
			if err != nil {
				return writeRepoErr(c, err)
			}
			data.Form = qaPlanFormData{Action: data.Base + "/plans", Err: "new-plan-error", Submit: "Create plan",
				Phase: "regression", PhaseOptions: qaPhaseOptions(), Scenarios: scenarios}
		}
		org, user, err := shellChrome(c, d.DB)
		if err != nil {
			return err
		}
		nav, err := qaNav(c, s, project, httpx.NavCrumb{Label: "Plans"})
		if err != nil {
			return writeRepoErr(c, err)
		}
		c.Type("html")
		return renderPage(c, d, "pages/qa_plans.html", httpx.ViewData{
			Title: "Plans · " + project.Name, Org: org, User: user, Nav: nav, Data: data,
		})
	}
}

func qaPlanPage(d Deps) fiber.Handler {

		if err != nil {
			return err
		}
		plan, err := loadQAPlan(c, s, project)
		if err != nil {
			return err
		}
		canWrite := mustPrincipal(c).Can("qa.plan.write")
		data := qaPlanData{Project: *project, Base: qaBase(project), Plan: *plan, PhaseLabel: qaPhaseLabels[plan.Phase],
			Window: qaWindow(plan.StartsOn, plan.EndsOn), CanWrite: canWrite && plan.ClosedAt == nil, CanCopy: canWrite,
			CopyName: plan.Name + " (copy)"}
		scenarioIDs, err := repo.ListQAPlanScenarioIDs(c.Context(), s, plan.ID)
		if err != nil {
			return writeRepoErr(c, err)
		}
		inPlan := map[uuid.UUID]bool{}
		for _, id := range scenarioIDs {
			inPlan[id] = true
		}
		all, err := repo.ListQAScenarios(c.Context(), s, project.ID, true)
		if err != nil {
			return writeRepoErr(c, err)
		}

			if inPlan[sc.ID] {
				data.Scenarios = append(data.Scenarios, qaScenarioRow{QAScenario: sc, PhaseLabel: qaPhaseLabels[sc.Phase],
					Href: data.Base + "/scenarios/" + sc.ID.String()})

		runs, err := repo.ListQARuns(c.Context(), s, plan.ID)
		if err != nil {
			return writeRepoErr(c, err)
		}
		runIDs := make([]uuid.UUID, len(runs))
		names := map[uuid.UUID]string{}
		for i, r := range runs {
			runIDs[i], names[r.ID] = r.ID, r.Name
		}
		progress, err := repo.QARunProgressFor(c.Context(), s, runIDs)
		if err != nil {
			return writeRepoErr(c, err)
		}
		for _, r := range runs {
			row := qaPlanRunRow{QARun: r, Href: data.Base + "/runs/" + r.ID.String(), Progress: progress[r.ID]}
			if r.RetestOf != nil {
				row.RetestOf, row.RetestHref = names[*r.RetestOf], data.Base+"/runs/"+r.RetestOf.String()
			}
			data.Runs = append(data.Runs, row)
		}
		planProgress, err := repo.QAPlanProgress(c.Context(), s, []uuid.UUID{plan.ID})
		if err != nil {
			return writeRepoErr(c, err)
		}
		data.Progress = planProgress[plan.ID]
		if data.CanWrite {
			options, err := qaPlanScenarioOptions(c, s, project, scenarioIDs)
			if err != nil {
				return writeRepoErr(c, err)
			}
			data.Form = qaPlanFormData{Action: planURL(project, plan), Err: "edit-plan-error", Submit: "Save",
				Name: plan.Name, Phase: plan.Phase, Environment: plan.Environment, Build: plan.Build,
				StartsOn: dateValue(plan.StartsOn), EndsOn: dateValue(plan.EndsOn),
				PhaseOptions: qaPhaseOptions(), Scenarios: options}
		}
		org, user, err := shellChrome(c, d.DB)
		if err != nil {
			return err
		}
		nav, err := qaNav(c, s, project, httpx.NavCrumb{Label: "Plans", Href: data.Base + "/plans"}, httpx.NavCrumb{Label: plan.Name})
		if err != nil {
			return writeRepoErr(c, err)
		}
		c.Type("html")
		return renderPage(c, d, "pages/qa_plan.html", httpx.ViewData{
			Title: plan.Name + " · " + project.Name, Org: org, User: user, Nav: nav, Data: data,
		})
	}
}

func updateQAPlanUI(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		plan, err := loadQAPlan(c, s, project)
		if err != nil {
			return err
		}
		if plan.ClosedAt != nil {
			return qaFormError(c, d, fiber.StatusConflict, "This plan is closed.")
		}
		in, msg, err := readQAPlanForm(c, s, project)
		if err != nil {
			return err
		}
		if msg != "" {
			return qaFormError(c, d, fiber.StatusUnprocessableEntity, msg)
		}
		if err := repo.UpdateQAPlan(c.Context(), s, plan.ID, in); err != nil {
			if status, msg, ok := qaPlanNameErr(err); ok {
				return qaFormError(c, d, status, msg)
			}
			return err
		}
		setFlash(c, "qa.plan.saved", strings.TrimSpace(in.Name))
		return redirectAfterMutation(c, planURL(project, plan))
	}
}

// duplicateQAPlanUI starts the next cycle of work from a plan: the same
// phase, environment, build and scenarios, a new name, no dates.
func duplicateQAPlanUI(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		plan, err := loadQAPlan(c, s, project)
		if err != nil {
			return err
		}
		dup, err := repo.DuplicateQAPlan(c.Context(), s, plan.ID, c.FormValue("name"), qaActor(c))
		if err != nil {
			if status, msg, ok := qaPlanNameErr(err); ok {
				return qaFormError(c, d, status, msg)

		}

	}
}

func closeQAPlanUI() fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		plan, err := loadQAPlan(c, s, project)
		if err != nil {
			return err
		}
		if plan.ClosedAt != nil { // already closed: nothing to do, nothing to audit
			return redirectAfterMutation(c, planURL(project, plan))
		}
		if err := repo.CloseQAPlan(c.Context(), s, plan.ID); err != nil {
			return writeRepoErr(c, err)
		}
		raw, _ := json.Marshal(fiber.Map{"name": plan.Name, "project_id": project.ID})
		if err := repo.RecordAuditEvent(c.Context(), s, qaActor(c), "qa.plan.close", "qa_plan", &plan.ID, raw); err != nil {
			return writeRepoErr(c, err)
		}
		setFlash(c, "qa.plan.closed", plan.Name)
		return redirectAfterMutation(c, planURL(project, plan))
	}
}

### Task 3: Creating a run: scenarios, testers, distribution, live preview

`/plans/:pid/runs/new` sets up a run with a name, notes, a subset of the plan's scenarios, testers, and how the cases are shared out: leave unassigned, one by one in turn, or whole groups in turn. A preview panel (an htmx fragment) shows how many cases there are and how many each tester gets, and updates on every change. Testers are the people who can execute here: owners, admins and members, plus guests listed on the project. // qaRunErrMessage is the sentence for a refused run.
func qaRunErrMessage(err error, in repo.QARunInput) (int, string, bool) {
	switch {
	case errors.Is(err, repo.ErrQAClosed):
		return fiber.StatusConflict, "This plan is closed.", true
	case errors.Is(err, repo.ErrQAEmptyRun):
		return fiber.StatusUnprocessableEntity, "The run would have no cases.", true
	case errors.Is(err, repo.ErrInvalidInput) && len(in.Testers) == 0 && in.Distribution != "" && in.Distribution != repo.DistributeNone:
		return fiber.StatusUnprocessableEntity, "Choose at least one tester to share the cases between.", true
	case errors.Is(err, repo.ErrInvalidInput):
		return fiber.StatusUnprocessableEntity,
			fmt.Sprintf("Run name is required and can be at most %d characters.", repo.MaxQANameLength), true
	}
	return 0, "", false
}

### Task 4: The execution view: progress, groups, filters, recording results, attachments

`/projects/:id/qa/runs/:rid` shows the run's progress, overall and per tester. Items are grouped by `group_name`, each group collapsible with its own progress, and can be filtered by who (mine, unassigned) and by status. An item opens in place: its panel (an htmx fragment) shows the copied precondition and steps, the history with files, and, for people with `qa.execute` on an open run, the result form. The form offers Pass, Fail, Blocked or Skip, a comment and files; the keys p, f, b and s pick a result. // qaStatusTone maps an item or result status to a badge tone.
func qaStatusTone(status string) string {
	switch status {
	case "passed":
		return "pass"
	case "failed", "blocked":
		return "fail"
	}
	return "none"
}

// qaPeopleLabels names every active member of the organization (any
// role), for assignees and executors. Someone who has left shows as "—".
func qaPeopleLabels(c *fiber.Ctx, d Deps, s tenant.Scope) (map[uuid.UUID]string, error) {
	members, err := global.ListMembersForOrg(c.Context(), d.DB, s.OrgID())
	if err != nil {
		return nil, err
	}
	out := make(map[uuid.UUID]string, len(members))
	for _, m := range members {
		label := m.Name
		if strings.TrimSpace(label) == "" {
			label = m.Email
		}
		out[m.UserID] = label
	}
	return out, nil
}

func personLabel(labels map[uuid.UUID]string, id *uuid.UUID) string {
	if id == nil {
		return ""
	}
	if l, ok := labels[*id]; ok {
		return l
	}
	return "—"
}

// loadQAItem reads :iid, which must be an item of run.
func loadQAItem(c *fiber.Ctx, s tenant.Scope, run *repo.QARun) (*repo.QARunItem, error) {

func runProgress(c *fiber.Ctx, s tenant.Scope, run *repo.QARun, labels map[uuid.UUID]string) (qaRunProgressData, error) {
	total, per, err := repo.QARunProgress(c.Context(), s, run.ID)
	if err != nil {
		return qaRunProgressData{}, err
	}
	out := qaRunProgressData{Total: total}
	for id, p := range per {
		if id == uuid.Nil {
			continue
		}
		out.Testers = append(out.Testers, qaTesterProgress{Label: personLabel(labels, &id), Progress: p})
	}
	sort.Slice(out.Testers, func(i, j int) bool {
		return strings.ToLower(out.Testers[i].Label) < strings.ToLower(out.Testers[j].Label)
	})
	if p, ok := per[uuid.Nil]; ok {
		out.Testers = append(out.Testers, qaTesterProgress{Label: "Unassigned", Progress: p})
	}
	return out, nil
}

func humanSize(n int64) string {
	switch {
	case n >= 1<<20:
		return fmt.Sprintf("%.1f MB", float64(n)/(1<<20))
	case n >= 1<<10:
		return fmt.Sprintf("%d KB", n>>10)
	}
	return fmt.Sprintf("%d B", n)
}

func itemPanel(c *fiber.Ctx, d Deps, s tenant.Scope, project *repo.Project, run *repo.QARun, item *repo.QARunItem) (qaItemPanelData, error) {
	labels, err := qaPeopleLabels(c, d, s)
	if err != nil {
		return qaItemPanelData{}, err
	}
	refs, err := repo.QACaseRefs(c.Context(), s, []uuid.UUID{item.CaseID})
	if err != nil {
		return qaItemPanelData{}, err
	}
	ref := refs[item.CaseID]
	url := runURL(project, run) + "/items/" + item.ID.String()
	data := qaItemPanelData{
		Item: qaItemRow{QARunItem: *item, Key: ref.Key, Changed: ref.Version > item.CaseVersion, Tone: qaStatusTone(item.Status),
			Assignee: personLabel(labels, item.AssigneeID), Panel: url},
		Action: url + "/result", CanExecute: mustPrincipal(c).Can("qa.execute") && run.ClosedAt == nil,
	}
	results, err := repo.ListQAResults(c.Context(), s, item.ID)
	if err != nil {
		return data, err
	}
	for _, r := range results {
		id := r.ID
		files, err := repo.ListQAAttachments(c.Context(), s, repo.QAAttachmentOwner{ResultID: &id})
		if err != nil {
			return data, err
		}
		entry := qaHistoryEntry{QAResult: r, Tone: qaStatusTone(r.Status), By: personLabel(labels, r.CreatedBy)}
		for _, f := range files {
			entry.Files = append(entry.Files, qaFileLink{Name: f.FileName, Href: qaBase(project) + "/files/" + f.ID.String(), Size: humanSize(f.SizeBytes)})
		}
		data.History = append(data.History, entry)
	}
	if data.Progress, err = runProgress(c, s, run, labels); err != nil {
		return data, err
	}
	data.Progress.OOB = true
	return data, nil
}

// recordQAResultUI records one result (and its files) for an item. Every
// file is checked against the size limit before anything is written, so a
// refused upload leaves no result behind.
func recordQAResultUI(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		run, err := loadQARun(c, s, project)
		if err != nil {
			return err
		}
		item, err := loadQAItem(c, s, run)
		if err != nil {
			return err
		}
		refuse := func(status int, msg string) error {
			if c.Get("HX-Request") == "" {
				return fiber.NewError(status, msg)
			}
			data, err := itemPanel(c, d, s, project, run, item)
			if err != nil {
				return writeRepoErr(c, err)
			}
			data.Error = msg
			c.Type("html")
			return d.Renderer.RenderNamed(c, "qa_item_panel", data)
		}
		status := strings.TrimSpace(c.FormValue("status"))
		if !qaResultChoices[status] {
			return refuse(fiber.StatusUnprocessableEntity, "Choose a result: passed, failed, blocked or skipped.")
		}
		var files []*multipart.FileHeader
		if form, err := c.MultipartForm(); err == nil {
			files = form.File["file"]
		}
		for _, f := range files {
			if f.Size > repo.MaxQAAttachmentBytes {
				return refuse(fiber.StatusUnprocessableEntity, "Each file can be at most 20 MB.")
			}
		}
		result, err := repo.RecordQAResult(c.Context(), s, repo.QAResultInput{
			ItemID: item.ID, Status: status, Comment: c.FormValue("comment"), CreatedBy: qaActor(c),
		})
		if errors.Is(err, repo.ErrQAClosed) {
			return refuse(fiber.StatusConflict, "This run is closed.")
		}
		if err != nil {
			return writeRepoErr(c, err)
		}
		for _, fh := range files {
			f, err := fh.Open()
			if err != nil {
				return err
			}
			// A browser that does not know the type says octet-stream; let
			// SaveQAAttachment sniff it instead, so a screenshot shows inline.
			ctype := fh.Header.Get("Content-Type")
			if ctype == "application/octet-stream" {
				ctype = ""
			}
			_, err = repo.SaveQAAttachment(c.Context(), s, d.Blob, repo.QAAttachmentOwner{ResultID: &result.ID},
				fh.Filename, ctype, f, qaActor(c))
			f.Close()
			if errors.Is(err, repo.ErrQAAttachmentTooLarge) {
				return refuse(fiber.StatusUnprocessableEntity, "Each file can be at most 20 MB.")
			}
			if err != nil {
				return err
			}
		}
		if c.Get("HX-Request") == "" {
			return c.Redirect(runURL(project, run), fiber.StatusFound)
		}
		item, err = repo.GetQARunItem(c.Context(), s, item.ID)
		if err != nil {
			return writeRepoErr(c, err)
		}
		data, err := itemPanel(c, d, s, project, run, item)
		if err != nil {
			return writeRepoErr(c, err)
		}
		data.OOB = true
		c.Type("html")
		return d.Renderer.RenderNamed(c, "qa_item_panel", data)
	}
}

// qaFileUI serves an attachment of the project in the URL. Images other
// than SVG are shown inline; everything else downloads, typed as bytes,
// with nosniff and a sandbox, so an uploaded HTML or SVG file never runs
// in the app's origin.
func qaFileUI(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		id, err := uuid.Parse(c.Params("aid"))
		if err != nil {
			return fiber.ErrNotFound
		}
		pid, err := repo.QAAttachmentProjectID(c.Context(), s, id)
		if errors.Is(err, repo.ErrNotFound) || errors.Is(err, sql.ErrNoRows) || (err == nil && pid != project.ID) {
			return fiber.ErrNotFound
		}
		if err != nil {
			return err
		}
		a, err := repo.GetQAAttachment(c.Context(), s, id)
		if err != nil {
			return writeRepoErr(c, err)
		}
		rc, err := d.Blob.Open(c.Context(), a.StorageKey)
		if errors.Is(err, blob.ErrNotFound) {
			return fiber.ErrNotFound
		}
		if err != nil {
			return err
		}
		inline := strings.HasPrefix(a.ContentType, "image/") && !strings.Contains(a.ContentType, "svg")
		disposition, ctype := "attachment", "application/octet-stream"
		if inline {
			disposition, ctype = "inline", a.ContentType
		}
		c.Set(fiber.HeaderContentType, ctype)
		c.Set(fiber.HeaderContentDisposition, mime.FormatMediaType(disposition, map[string]string{"filename": a.FileName}))
		c.Set(fiber.HeaderXContentTypeOptions, "nosniff")
		c.Set(fiber.HeaderContentSecurityPolicy, "sandbox")
		return c.SendStream(rc, int(a.SizeBytes))
	}
}

func assignQAItemsUI(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		run, err := loadQARun(c, s, project)
		if err != nil {
			return err
		}
		ids, err := formUUIDs(c, "item_id")
		if err != nil {
			return err
		}
		if len(ids) == 0 {
			return qaFormError(c, d, fiber.StatusUnprocessableEntity, "Select at least one item.")
		}
		var assignee *uuid.UUID
		if raw := strings.TrimSpace(c.FormValue("assignee_id")); raw != "" {
			people, err := qaPeople(c, d, s, project)
			if err != nil {
				return writeRepoErr(c, err)
			}
			for _, p := range people {
				if p.ID.String() == raw {
					id := p.ID
					assignee = &id
				}
			}
			if assignee == nil {
				return fiber.ErrNotFound
			}
		}
		n, err := repo.AssignQARunItems(c.Context(), s, run.ID, ids, assignee)
		if err != nil {
			return writeRepoErr(c, err)
		}
		setFlash(c, "qa.items.assigned", strconv.Itoa(n))
		return redirectAfterMutation(c, runURL(project, run))
	}
}

// retestQARunUI starts the next cycle with the run's failed and blocked
// items, each given to whoever ran it, and opens it.
func retestQARunUI(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		run, err := loadQARun(c, s, project)
		if err != nil {
			return err
		}
		retest, err := repo.CreateQARetest(c.Context(), s, run.ID, qaActor(c))
		switch {
		case errors.Is(err, repo.ErrQAEmptyRun):
			return qaFormError(c, d, fiber.StatusUnprocessableEntity, "Nothing failed or blocked to retest.")
		case errors.Is(err, repo.ErrQAClosed):
			return qaFormError(c, d, fiber.StatusConflict, "This plan is closed.")
		case err != nil:
			return writeRepoErr(c, err)
		}
		setFlash(c, "qa.run.created", retest.Name)
		return redirectAfterCreate(c, qaBase(project)+"/runs/"+retest.ID.String())
	}
}

func closeQARunUI() fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		run, err := loadQARun(c, s, project)
		if err != nil {
			return err
		}
		if run.ClosedAt != nil { // already closed: nothing to do, nothing to audit
			return redirectAfterMutation(c, runURL(project, run))
		}
		if err := repo.CloseQARun(c.Context(), s, run.ID); err != nil {
			return writeRepoErr(c, err)
		}
		raw, _ := json.Marshal(fiber.Map{"name": run.Name, "plan_id": run.PlanID, "project_id": project.ID})
		if err := repo.RecordAuditEvent(c.Context(), s, qaActor(c), "qa.run.close", "qa_run", &run.ID, raw); err != nil {
			return writeRepoErr(c, err)
		}
		setFlash(c, "qa.run.closed", run.Name)
		return redirectAfterMutation(c, runURL(project, run))
	}
}

### Task 7: Save a run as a scenario; end-to-end execution

From a run, **Save as scenario…** keeps its case set for the next plan: a new scenario with the run's cases in run order and one group per group name the run used. +	name, err := normalizeQAName(name, MaxQANameLength)
+	if err != nil {
+		return nil, err
+	}

+		return nil, ErrInvalidInput
+	}

+		var projectID uuid.UUID
+		if err := tx.GetContext(ctx, &projectID, `
+			SELECT p.project_id FROM qa_runs r JOIN qa_plans p ON p.id = r.plan_id WHERE r.id = $1`, runID); err != nil {
+			return err
+		}
+		if err := tx.GetContext(ctx, &out, `

+			VALUES ($1, $2, $3, $4, $5) RETURNING `+qaScenarioCols, s.OrgID(), projectID, name, phase, createdBy); err != nil {
+			return err
+		}
+		var items []struct {
+			CaseID    uuid.UUID `db:"case_id"`
+			GroupName string    `db:"group_name"`
+		}
+		if err := tx.SelectContext(ctx, &items, `
+			SELECT i.case_id, i.group_name FROM qa_run_items i JOIN qa_cases c ON c.id = i.case_id
+			WHERE i.run_id = $1 AND c.archived_at IS NULL ORDER BY i.position`, runID); err != nil {
+			return err
+		}

+		for pos, it := range items {
+			g, ok := groups[it.GroupName]
+			if !ok {
+				var id uuid.UUID
+				if err := tx.GetContext(ctx, &id, `
+					INSERT INTO qa_scenario_groups (org_id, scenario_id, name, position) VALUES ($1, $2, $3, $4) RETURNING id`,
+					s.OrgID(), out.ID, truncateQAName(it.GroupName), len(groups)); err != nil {
+					return err
+				}
+				g = &id
+				groups[it.GroupName] = g
+			}
+			if _, err := tx.ExecContext(ctx, `

+			}
+		}
+		return nil
+	})

+	}

### Task 8: Large runs and scenarios open with their groups closed

Added after validation, on the user's decision (2026-09-27), from the production sizes: one run holds 1,089 items and 13 are over 500, while pagination would split a group's progress and its select-whole-group assignment.
