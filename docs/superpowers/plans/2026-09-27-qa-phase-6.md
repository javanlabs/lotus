# QA module — Phase 6: Issues — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let testers and clients report issues from what they tested, and let the team triage them: an issue list with filters and paging, reporting from a run item or on its own, and an issue page with fields, status, a timeline of changes and comments, files, and the run items it was found in.

**Architecture:** The same shape as Phases 4 and 5. Every route is registered with `qaRoute`, and every id is checked against the project (`qaOwned`, `optionalOwned`, `qaPeople`). Files go through `saveQAFiles` into the blob store and are served by Phase 5's `/qa/files/:aid`. The report form and the edit dialog share their fields (`qa_issue_fields`, `readQAIssueFields`, `fillQAIssueOptions`).

**Tech Stack:** Go 1.26, Fiber v2, html/template, htmx, Alpine.js, Basecoat combobox (`lotus_select`), Postgres 16+, Playwright.

**Spec:** `docs/superpowers/specs/2026-09-27-qa-module-design.md` (§4 `qa_issues`, `qa_issue_events`, `qa_issue_links`; §5 permissions). **Parent plan:** `docs/superpowers/plans/2026-09-27-qa-module.md`, "Phase 6 — Issues". **Previous phases:** `…/2026-09-27-qa-phase-4.md`, `…/2026-09-27-qa-phase-5.md` (helpers used here: `qaRoute`, `qaOwned`, `qaNav`, `qaFormError`, `qaPeople`, `qaPeopleLabels`, `personLabel`, `qaStatusTone`, `humanSize`, `qaFileLink`, test helpers `newQARunEnv`, `qaRunEnv.firstRun`, `qaFile`).

**Status:** Validated. Every task was implemented in a scratch worktree exactly as written, one commit per task. Each commit on its own passes `go build`, `go vet`, `gofmt`, `make lint` and its tests. After Task 3 the full Go suite and all 36 Playwright specs pass. ## Decisions

- **Guests see every issue of the projects they are listed on**, internal ones included. The spec gives a guest `qa.read` on its projects and does not narrow issues further. *To revisit with the user:* if clients should see only client issues and issues linked to items they ran, it is a filter in `qaIssuesPage` and a check in `loadQAIssue`.
- **The list opens on open issues**: new, open, fixed and reopened (`repo.QAOpenIssueStatuses`, where fixed counts because it awaits confirmation). Closed, invalid and duplicate are one click away.
- **An issue's source follows who reported it**: `client` for a guest, `internal` for everyone else. It is not a field anyone edits.
- **Assigning is triage**: only `qa.issue.write` sets an assignee, when reporting or editing. Assignees are the people who can execute here (Phase 5's `qaPeople`).

## Rulings (where this plan departs from the Phase 6 outline)

1. **6.4 attachment download was delivered in Phase 5** (`qaFileUI`: project check, nosniff, sandbox CSP, inline only for non-SVG images). Phase 6 adds the tests for issue and comment files (Task 3).
2. **Links between issues and items are made by reporting from an item.** There is no separate link or unlink control; the outline does not ask for one.

## Global Constraints

- Everything in Phases 4 and 5's Global Constraints still holds.
- Permissions exactly as spec §5:
  - `qa.read`: the list and the issue page.
  - `qa.issue.report`: reporting and commenting, for guests too, on their projects.
  - `qa.issue.write`: editing fields, changing status and assigning.
- Files: at most 20 MB each, checked before anything is written, refused with a message; the browser-side check from Phase 5 (`data-max-file-bytes`) is used on the comment form too.
- Issue keys are shown as `BUG-<key>` and case keys as `TC-<key>`.

## Review Focus

1. **Ids from another project**: a plan, section, item or assignee in the report or edit form, or an issue key from another project, must be 404. Pinned in Tasks 2 and 3.
2. **Guests**: a guest reports client issues and comments with files, but cannot edit, change status or assign, and never sees another project's issues or files. Pinned in Tasks 1, 2 and 3.
3. **Markup in titles, descriptions, steps and comments** renders as text on the list, the issue page, the item panel and the timeline. Pinned in Tasks 1 and 3.
4. **Status history**: a status change writes exactly one event with its note, an unchanged status writes none, and the timeline shows `from → to`. Pinned in Task 3.
5. **A large issue list**: 579 issues in the largest production project; the list pages at 100, and filters and search keep their values across pages. Pinned in Task 1.

### Task 1: The issue list: filters, search, paging

`/projects/:id/qa/issues` lists a project's issues, newest first. It can be filtered by status (open, which is the default, closed or all), severity, source, plan and a literal title search, and is paged 100 per page because production projects hold up to 579 issues. Each row shows the key, title, severity, status, assignee, plan and last update. Client issues carry a badge, and titles are escaped. The QA segmented control gains **Issues**, and the landing's Open issues tile links to it.

package web

import (
	"net/url"
	"strconv"
	"strings"

	"github.com/gofiber/fiber/v2"
	"github.com/google/uuid"

	"github.com/uyab/lotus/internal/httpx"
	"github.com/uyab/lotus/internal/repo"
)

// qaIssuesPerPage bounds the issue list: production projects hold up to
// 579 issues. Filters and the search box narrow it; the pager walks the rest.
const qaIssuesPerPage = 100

// qaClosedIssueStatuses are the statuses that need no more work.
var qaClosedIssueStatuses = []string{"closed", "invalid", "duplicate"}

// qaSeverityTone: the two severities that stop testing read as failures.
func qaSeverityTone(sev string) string {
	if sev == "blocker" || sev == "critical" {
		return "fail"
	}
	return "none"
}

type qaIssueRow struct {
	repo.QAIssue
	Href         string
	SeverityTone string
	Assignee     string
	PlanName     string
}

type qaIssuesData struct {
	Project     repo.Project
	Base        string
	Rows        []qaIssueRow
	Status      string // "open" (default), "closed", "all"
	Severity    string
	Source      string
	Plan        string
	Query       string
	Total       int
	Page, Pages int
	From, To    int
	PrevHref    string
	NextHref    string
	CanReport   bool

	StatusOptions   []httpx.SelectOption
	SeverityOptions []httpx.SelectOption
	SourceOptions   []httpx.SelectOption
	PlanOptions     []httpx.SelectOption
}

// url is the list with the current filters and page p.
func (d qaIssuesData) url(p int) string {
	v := url.Values{}
	for k, val := range map[string]string{"status": d.Status, "severity": d.Severity, "source": d.Source, "plan": d.Plan, "q": d.Query} {
		if val != "" && !(k == "status" && val == "open") {
			v.Set(k, val)
		}
	}
	if p > 1 {
		v.Set("page", strconv.Itoa(p))
	}
	if len(v) == 0 {
		return d.Base + "/issues"
	}
	return d.Base + "/issues?" + v.Encode()
}

func qaSeverityOptions(any string) []httpx.SelectOption {
	out := []httpx.SelectOption{}
	if any != "" {
		out = append(out, httpx.SelectOption{Value: "", Label: any})
	}
	for _, s := range repo.QAIssueSeverities {
		out = append(out, httpx.SelectOption{Value: s, Label: s})
	}
	return out
}

func qaIssuesPage(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		data := qaIssuesData{Project: *project, Base: qaBase(project),
			Status: c.Query("status", "open"), Severity: c.Query("severity"), Source: c.Query("source"),
			Plan: c.Query("plan"), Query: strings.TrimSpace(c.Query("q")),
			CanReport: mustPrincipal(c).Can("qa.issue.report")}
		filter := repo.QAIssueFilter{Query: data.Query}
		switch data.Status {
		case "closed":
			filter.Statuses = qaClosedIssueStatuses
		case "all":
		default:
			data.Status, filter.Statuses = "open", repo.QAOpenIssueStatuses
		}
		for _, sev := range repo.QAIssueSeverities {
			if sev == data.Severity {
				filter.Severity = sev
			}
		}
		if data.Source == "internal" || data.Source == "client" {
			filter.Source = data.Source
		} else {
			data.Source = ""
		}
		if data.Plan != "" {

			}

		}
		planNames := map[uuid.UUID]string{}
		data.PlanOptions = []httpx.SelectOption{{Value: "", Label: "Any plan"}}
		for _, p := range plans {
			planNames[p.ID] = p.Name
			data.PlanOptions = append(data.PlanOptions, httpx.SelectOption{Value: p.ID.String(), Label: p.Name})
		}
		data.StatusOptions = []httpx.SelectOption{{Value: "open", Label: "Open"}, {Value: "closed", Label: "Closed"}, {Value: "all", Label: "All"}}
		data.SeverityOptions = qaSeverityOptions("Any severity")
		data.SourceOptions = []httpx.SelectOption{{Value: "", Label: "Any source"}, {Value: "internal", Label: "internal"}, {Value: "client", Label: "client"}}

		}

		}

			Title: "Issues · " + project.Name, Org: org, User: user, Nav: nav, Data: data,
		})
	}

// Reporting an issue (qa.issue.report): standalone, or from a run item,
// which pre-fills the title, steps, environment and plan from what the run
// holds and links the issue to the item. A guest's issue is a client issue;
// only people with qa.issue.write choose an assignee.

type qaIssueFormData struct {
	Project          repo.Project
	Base             string
	ItemID           string
	ItemLabel        string // "TC-3 Login · Cycle 1", when reported from an item
	Title            string
	Severity         string
	Description      string
	StepsToReproduce string
	Environment      string
	PlanID           string
	SectionID        string
	AssigneeID       string
	CanAssign        bool
	Error            string
	MaxFileBytes     int
	SeverityOptions  []httpx.SelectOption
	PlanOptions      []httpx.SelectOption
	SectionOptions   []httpx.SelectOption
	PeopleOptions    []httpx.SelectOption
}

// qaStepsText writes a run item's steps as the numbered text an issue
// carries: "1. Open the portal → Login page".
func qaStepsText(steps repo.QASteps) string {
	var b strings.Builder
	for i, s := range steps {
		fmt.Fprintf(&b, "%d. %s", i+1, s.Action)
		if s.Expected != "" {
			fmt.Fprintf(&b, " → %s", s.Expected)
		}
		b.WriteString("\n")
	}
	return strings.TrimSpace(b.String())
}

// qaIssueItem reads an item id (query or form) of the project in the URL,
// with its run and plan.
func qaIssueItem(c *fiber.Ctx, s tenant.Scope, project *repo.Project, raw string) (*repo.QARunItem, *repo.QARun, *repo.QAPlan, error) {
	id, err := qaOwned(c, s, project, repo.QAKindItem, raw)
	if err != nil {
		return nil, nil, nil, err
	}
	item, err := repo.GetQARunItem(c.Context(), s, id)
	if err != nil {
		return nil, nil, nil, err
	}
	run, err := repo.GetQARun(c.Context(), s, item.RunID)
	if err != nil {
		return nil, nil, nil, err
	}
	plan, err := repo.GetQAPlan(c.Context(), s, run.PlanID)
	return item, run, plan, err
}

func newQAIssuePage(d Deps) fiber.Handler {
	return func(c *fiber.Ctx) error {
		s, project, err := loadQAProject(c)
		if err != nil {
			return err
		}
		f := qaIssueFormData{Project: *project, Base: qaBase(project)}
		if raw := c.Query("item"); raw != "" {
			item, run, plan, err := qaIssueItem(c, s, project, raw)
			if err != nil {
				return err
			}
			refs, err := repo.QACaseRefs(c.Context(), s, []uuid.UUID{item.CaseID})
			if err != nil {
				return writeRepoErr(c, err)
			}
			f.ItemID = item.ID.String()
			f.ItemLabel = fmt.Sprintf("TC-%d %s · %s", refs[item.CaseID].Key, item.Title, run.Name)
			f.Title = truncateRunes("Fail: "+item.Title, repo.MaxQATitleLength)
			f.StepsToReproduce = qaStepsText(item.Steps)
			f.Environment = plan.Environment
			f.PlanID = plan.ID.String()
		}
		return renderQAIssueForm(c, d, s, f, fiber.StatusOK)
	}
}

func truncateRunes(s string, n int) string {
	r := []rune(s)
	if len(r) <= n {
		return s
	}
	return string(r[:n-1]) + "…"
}

// optionalOwned reads an optional id field that must belong to the project.
func optionalOwned(c *fiber.Ctx, s tenant.Scope, project *repo.Project, kind repo.QAKind, raw string) (*uuid.UUID, error) {
	if strings.TrimSpace(raw) == "" {
		return nil, nil
	}
	id, err := qaOwned(c, s, project, kind, raw)
	if err != nil {
		return nil, err
	}
	return &id, nil
}

// saveQAFiles stores each file for owner. A browser that does not know a
// file's type says octet-stream; SaveQAAttachment sniffs it instead.
func saveQAFiles(c *fiber.Ctx, d Deps, s tenant.Scope, owner repo.QAAttachmentOwner, files []*multipart.FileHeader) error {
	for _, fh := range files {
		f, err := fh.Open()
		if err != nil {
			return err
		}
		ctype := fh.Header.Get("Content-Type")
		if ctype == "application/octet-stream" {
			ctype = ""
		}
		_, err = repo.SaveQAAttachment(c.Context(), s, d.Blob, owner, fh.Filename, ctype, f, qaActor(c))
		f.Close()
		if err != nil {
			return err
		}
	}
	return nil
}

// loadQAIssue reads :key within the project in the URL.
func loadQAIssue(c *fiber.Ctx, s tenant.Scope, project *repo.Project) (*repo.QAIssue, error) {
	key, err := strconv.Atoi(c.Params("key"))
	if err != nil || key < 1 {
		return nil, fiber.ErrNotFound
	}
	is, err := repo.GetQAIssueByKey(c.Context(), s, project.ID, key)
	if errors.Is(err, repo.ErrNotFound) {
		return nil, fiber.ErrNotFound
	}
	return is, err
}

func issueURL(project *repo.Project, is *repo.QAIssue) string {
	return fmt.Sprintf("%s/issues/%d", qaBase(project), is.Key)

func qaFileLinks(c *fiber.Ctx, s tenant.Scope, project *repo.Project, owner repo.QAAttachmentOwner) ([]qaFileLink, error) {
	files, err := repo.ListQAAttachments(c.Context(), s, owner)
	if err != nil {
		return nil, err
	}
	out := make([]qaFileLink, 0, len(files))
	for _, f := range files {
		out = append(out, qaFileLink{Name: f.FileName, Href: qaBase(project) + "/files/" + f.ID.String(), Size: humanSize(f.SizeBytes)})
	}
	return out, nil
}

// readQAIssueFields reads the fields both the report form and the edit
// dialog send, checking every id against the project and the assignee
// against the people who can execute here (404 otherwise).
func readQAIssueFields(c *fiber.Ctx, d Deps, s tenant.Scope, project *repo.Project, in *repo.QAIssueInput) error {
	in.Title, in.Severity = c.FormValue("title"), strings.TrimSpace(c.FormValue("severity"))
	in.Description, in.StepsToReproduce = c.FormValue("description"), c.FormValue("steps_to_reproduce")
	in.Environment = c.FormValue("environment")
	var err error
	if in.PlanID, err = optionalOwned(c, s, project, repo.QAKindPlan, c.FormValue("plan_id")); err != nil {
		return err
	}
	if in.SectionID, err = optionalOwned(c, s, project, repo.QAKindSection, c.FormValue("section_id")); err != nil {
		return err
	}
	in.AssigneeID = nil
	if raw := strings.TrimSpace(c.FormValue("assignee_id")); raw != "" && mustPrincipal(c).Can("qa.issue.write") {
		people, err := qaPeople(c, d, s, project)
		if err != nil {
			return err
		}
		for _, p := range people {
			if p.ID.String() == raw {
				id := p.ID
				in.AssigneeID = &id
			}
		}
		if in.AssigneeID == nil {
			return fiber.ErrNotFound
		}
	}
	return nil
}
